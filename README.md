# [KDD 2025] Improving Group Robustness on Spurious Correlation via Evidential Alignment

This paper has been accepted by KDD 2025 and won the 🏆 Best Paper Award 🏆 (Research Track). 

## Datasets
- [Waterbirds](https://nlp.stanford.edu/data/dro/waterbird_complete95_forest2water2.tar.gz)
- [CelebA](https://www.kaggle.com/datasets/jessicali9530/celeba-dataset) ([metadata](https://github.com/PolinaKirichenko/deep_feature_reweighting/blob/main/celeba_metadata.csv))
- [CivilComments](https://wilds.stanford.edu/datasets/): The dataset will be automatically downloaded from the package `wilds`
- [MultiNLI](https://cims.nyu.edu/~sbowman/multinli/): Call the function `download` in `data/multinli.py` to download the dataset.
- [CheXpert](https://stanfordmlgroup.github.io/competitions/chexpert/): The dataset should be downloaded from [CheXpert](https://stanfordmlgroup.github.io/competitions/chexpert/) and the metadata should be generated by running the function `generate_metadata_chexpert` in `data/chexpert.py`.

Unzip the dataset files into individual folders.

In the `config.py` file, set each value in `dataset_paths` to your corresponding dataset folder. 

## Example Usage
```bash
python main.py --dataset waterbirds \
    --save_folder /path/to/save_folder \
    --backbone resnet50 \
    --batch_size 128 \
    --pretrained True \
    --mode train \
    --split_train 1.0 \
    --split_val 0.4 \
    --train_split val_subset1 \
    --test_split test \
    --erm_model /model/path/to/erm_model.pt \
    --optimizer_cls sgd \
    --optimizer_cls_kwargs lr=0.01 weight_decay=0 momentum=0.0 \
    --algorithm evidential_alignment \
    --edl_lr 0.01 \
    --alignment_lr 0.01 \
    --reg_weight 0.1 \
    --annealing_step 10 \
    --edl_epochs 50 \
    --alignment_epochs 100 \
    --balance_classes True \
    --result_path /path/to/result.txt
```
